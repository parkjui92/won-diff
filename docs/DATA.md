# 공개 KIAT 자료의 출처와 가공

원천: [한국산업기술진흥원 수입·지출 현황, 2025년 1/4분기 ALIO 공시](https://alio.go.kr/upload/disclosure/2025/04/10/2025041002977191/doc.html).
기준일 2024-12-31, 제출일 2025-04-10, 조회일 2026-10-21.

원문 HTML SHA-256:
`f02745d91ee328a85c0dececc3615f697d5a243c8f2902f9b91289e69c29300c`.

## 발췌한 사실값

원문 단위는 백만원이다.

| 항목 | 2023 결산 | 2024 결산 | 2025 예산 |
|---|---:|---:|---:|
| 출연금 | 6,826 | 6,826 | 6,771 |
| 이전수입 | 931 | 933 | 983 |
| 위탁수입 | 79,680 | 82,547 | 95,243 |
| 정부지원수입 소계 | 87,437 | 90,306 | 102,997 |

화면 예제는 2024년 값을 100으로 나눠 억원으로 정확히 환산하고, 행 순서도 바꾼다.
출연금 68.26, 이전수입 9.33, 위탁수입 825.47, 소계 903.06억원이다.

독립 검산:

- 2023: 6,826 + 931 + 79,680 = 87,437백만원.
- 2024: 6,826 + 933 + 82,547 = 90,306백만원.
- 차액: 90,306 − 87,437 = 2,869백만원 = **28.69억원**.
- 이전수입 차액: 2백만원 = 0.02억원.
- 위탁수입 차액: 2,867백만원 = 28.67억원.
- 출연금 차액: 0.

원문에는 정부지원수입의 다른 항목에 `-`가 있다. 예제는 **숫자가 명시된 3개 항목과
소계만 발췌**했다. 제외한 `-`를 0으로 바꾸지 않았다. 세 항목 합산과 공시 소계가
일치하는 것은 발췌 범위의 대조 결과이며, 전체 회계 자료의 완전성 판정이 아니다.

## 회계 기준

원문 작성기준은 당해연도 예산을 현금주의, 과년도 회계결산을 발생주의로 작성한다고 설명한다.
반올림으로 합계 간 금액 차이가 생길 수 있다는 설명도 있다.

따라서 `basis-mapping.json`으로 2024 결산과 2025 예산을 비교하면 기준 차이를
경고하고 증감률을 출력하지 않는다. 산술 차액 12,691백만원은 수학적 차이이며
동일 기준의 사업 확장·축소나 성과를 뜻하지 않는다.

## 파일

- `kiat-2023-백만원.csv`, `kiat-2024-백만원.csv`, `kiat-2025-백만원.csv`: 공개 수치 발췌.
- `kiat-2024-억원.csv`: 2024년 금액을 정확히 환산한 사본.
- `source.json`: URL·판본·원문 해시·발췌 행·주석.
- `mapping.json`: 2023/2024 결산 비교 설정.
- `basis-mapping.json`: 2024 결산/2025 예산 비교 설정.

소계 1백만원 오류 실험은 테스트 실행 중 메모리의 사본에만 넣는다.
공개 입력 파일을 오류 데이터로 덮어쓰지 않는다.

## 다시 수집

Python 표준 라이브러리만으로:

```bash
python3 scripts/fetch-kiat.py
```

회사 프록시 등의 인증서가 Python에 설정되지 않았다면, 인증서를 검증할 수 있는
환경의 curl로 같은 URL을 저장한 다음 `--html`로 전달할 수 있다. 인증서 검증을
끄는 옵션은 사용하지 않는다.

```bash
curl --fail --location 'https://alio.go.kr/upload/disclosure/2025/04/10/2025041002977191/doc.html' -o /tmp/kiat.html
python3 scripts/fetch-kiat.py --html /tmp/kiat.html
```

담당자 이름·전화번호·전체 HTML은 저장소에 싣지 않는다. 이 예제는 최신 예산 조회 서비스가 아니라
특정 공개 판본을 이용한 재현 가능한 검증이다.
