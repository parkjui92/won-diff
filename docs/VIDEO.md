# 한국어 설명 영상

[영상 재생](https://parkjui92.github.io/won-diff/demo.html) · [MP4](assets/demo-ko.mp4) · [한국어 자막](assets/demo-ko.vtt)

약 1분 59초. 실제 Chrome 화면을 조작해 녹화한 1440×1000 H.264/AAC 영상입니다.
한국어 내레이션은 macOS Yuna 합성 음성입니다. 화면 요약 자막과 별도의 전체 음성 자막을 제공합니다.
자막 문장별 시점은 장면 안에서 길이에 따라 배분한 근사값입니다.

## 0:00 한국어 예산표, 실제 금액의 차이만

원디프는 한국어 예산표의 실제 금액 변경을 검토하는 도구입니다. 천 곱하기 백만원은 십억원과 같습니다. 단위만 바뀐 것을 예산이 줄었다고 읽지 않도록, 먼저 원 단위로 맞춥니다.

## 0:13 실제 KIAT 공개자료로 시작

공개자료 예제를 누르면, 알리오에 공개된 한국산업기술진흥원의 정부지원수입 표를 불러옵니다. 이천이십삼년과 이천이십사년 결산을 비교합니다. 비교 파일은 같은 원문 값을 억원으로 환산한 사본입니다.

## 0:28 금액 변경 2건 · 표기 변경 1건

비교 결과 실제 금액이 바뀐 항목은 두 건입니다. 상세 합계의 차이는 이십팔점 육구억원입니다. 지정한 소계와 상세 합산도 맞는지 대조합니다. 사업의 원인이나 정책 성과를 자동으로 추론하지는 않습니다.

## 0:43 출연금은 줄지 않았습니다

표기와 단위만 변경된 항목을 고르면 출연금이 남습니다. 육천팔백이십육 백만원과 육십팔점 이육억원은 같습니다. 근거 버튼에서 원래 값, 셀 주소, 환산식과 파일 해시를 확인할 수 있습니다.

## 0:58 결산과 예산을 섞으면 알립니다

회계 기준을 예산으로 바꾸면 이전 결과를 지우고 재검토를 요구합니다. 결산과 예산처럼 기준이 다를 때는 차액만 제시하고 증감률은 계산하지 않습니다. 이 기준은 사용자가 원문을 확인하고 선택합니다.

## 1:13 중복 식별자는 조용히 덮어쓰지 않음

이번에는 일부러 같은 식별자를 두 번 넣은 합성 파일입니다. 도구는 뒤의 값으로 덮어쓰지 않고 비교를 중단합니다. 빈 금액과 수식도 확정된 영으로 처리하지 않습니다.

## 1:26 검토 결과와 근거를 함께 저장

정상 예제로 돌아와 결과를 저장합니다. 씨에스브이에는 변경표가, 제이슨에는 설정과 파일 해시를 포함한 검토 근거가 담깁니다. 오프라인 파일은 인터넷 연결 없이 엑셀 파일도 비교합니다. 원본 파일은 수정하지 않습니다.

## 1:42 차별점도 같은 입력으로 검증

기존 공개 도구 세 가지와 같은 스물네 쌍을 비교했습니다. 원디프는 금액이 같은 표현 변경 열 건을 따로 구분했습니다. 기존 도구도 단위를 전처리하면 같은 결과를 냅니다. 환산과 근거 정리를 한 번에 처리하는 것이 이 도구의 장점입니다.

## 재제작

macOS의 `say -v Yuna`, ffmpeg/ffprobe, Chrome이 필요합니다. 먼저 앱을 4173 포트에서 실행합니다.

```bash
node scripts/record-demo.mjs
node scripts/build-video-docs.mjs
npm run build
```

촬영 중간 파일은 `docs/video-work/`에만 저장하며 Git에서는 제외합니다. 배포 파일은
`docs/assets/`에 저장합니다. 개인정보나 실제 내부 파일을 사용하지 않습니다.
영상의 오류 예제는 합성 데이터이며 실제 KIAT 공시의 오류를 의미하지 않습니다.
