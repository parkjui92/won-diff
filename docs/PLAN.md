# won-diff 개발·검증 계획

기획 기준일: 2026-10-21. 개발자: 박주이.

## 해결할 일

정책기획·사업관리 담당자가 전년도/당해연도 예산표나 원안/수정안의 차이를 확인할 때,
행 순서와 원·백만원·억원 단위가 달라진 것을 실제 증감으로 오인하지 않도록 한다.
두 파일의 식별자, 금액 열, 단위, 회계 기준을 지정하면 원 단위로 환산한 변경표와
원본 셀 좌표, 환산 근거, 검토할 항목을 함께 남긴다.

KIAT 공개 ALIO 공시에는 백만원 단위 금액과 “당해연도 예산(현금주의) /
과년도 결산(발생주의)”라는 주석이 있다. 따라서 금액 계산뿐 아니라 비교 기준이
다를 때 증감률을 일반적인 성과·추세로 제시하지 않는 처리가 필요하다.

## 기존 개발물과 구분

- `kr-sti-data`: 통계 수집·시계열 단절 표시. 이 도구는 사용자가 가진 표 두 개의 셀을 대조.
- `rnd-eval-skills/budget-trend-read`: AI가 예산 추이를 해석하는 절차. 이 도구는 해석 전 숫자 검산을 수행.
- `fact-verify`: 주장과 문헌 근거 대조. 이 도구는 금액 환산·행 대응·총액 대조를 결정론적으로 수행.
- 기존 강의·시연 파일은 수정하거나 공개 저장소에 포함하지 않음.

## 비교 대상과 검증 가설

1. [daff](https://github.com/paulfitz/daff): 행·열 정렬, 패치/병합, HTML 출력이 강점.
2. [csv-diff](https://github.com/simonw/csv-diff): 키 기반 CSV/JSON 비교와 간결한 CLI가 강점.
3. [TabularDelta](https://github.com/Quantco/tabulardelta): 데이터프레임·SQL 비교, 스키마 변경, 다양한 출력이 강점.

가설: 한국 원화 단위가 다른 **원본 금액 표현 그대로**를 입력하는 제한된 업무에서,
단위 환산이 없는 범용 비교보다 실질 변경 판정의 정확도가 높다.
각 도구의 의도한 기능 차이를 공개하고, 보편적인 우월성이나 속도 우위는 주장하지 않는다.
동일한 키·동일한 숫자 표기 조건도 포함한다. 단위 정규화 전처리를 붙인 범용 도구도
같은 결과를 낼 수 있음을 명시한다.

## 구현 범위

- 서버·LLM·API 키 없이 브라우저 내 처리, 같은 계산 모듈을 쓰는 Node CLI.
- CSV/TSV, Excel XLSX 읽기. 시트·헤더행·키 열·금액 열·단위 선택.
- 원/천원/만원/백만원/억원/조원, 쉼표, 소수, 괄호·△ 음수, 셀 단위 표기.
- 식별자에 따른 대응; 추가·삭제·증감·표기변경·결측/해석불가 구분.
- 결측과 0 구분, 중복 키·헤더 오류 차단, 수식 금액은 값으로 확정 전 검토 요청.
- 사용자가 명시한 평면 합계 행과 상세 합계 대조. 합계 미지정·결측 시 완전한 총액을 주장하지 않음.
- 기준이 다른 비교의 경고와 증감률 억제, 파일 해시와 원본 셀 좌표 포함.
- 검토 CSV/JSON 저장, 필터·검색·세부 근거 보기. 원본 파일에 쓰지 않음.

범위 밖: HWP/PDF OCR, 임의 계층표 자동 해석, 회계 적정성 판단, 사업명 의미 매칭,
AI에 의한 증감 원인 추론, 데이터 자동 수집, 외부 서비스 업로드.

## 수용 기준

- 수치/단위 경계조건 및 오류 입력 검사, 무작위 생성 불변식 검사를 통과.
- 공개 ALIO 자료의 두 결산연도와 단위변환 사본을 원문과 독립 계산으로 대조.
- 공개 자료에 의도적으로 넣은 오류는 별도 합성 실험으로 명시.
- 비교 대상 실제 실행 결과와 버전·재현 명령·한계 공개.
- 브라우저에서 업로드 → 설정 → 결과 → 다운로드, 모바일, 네트워크 비전송 확인.
- GitHub Actions 테스트·Pages 배포 성공, 태그/릴리스, README의 한국어 설명 영상.
- 강의 검토는 별도 위치→문제→근거→수정 제안으로 전달하고 원본 해시 불변 확인.
